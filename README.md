# Food Delivery Web Application

A full-stack food delivery platform built using React.js, Node.js, Express.js, and MongoDB.

## Features

- User Authentication
- Browse Food Items
- Add to Cart
- Place Orders
- Order Management
- Admin Dashboard
- Responsive Design

## Tech Stack

### Frontend
- React.js
- Context API
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
